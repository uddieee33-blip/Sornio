A FEW THINGS TO KNOWBEFORE YOU BEGIN
Does Sornio need the internet for everyday billing?

The native Windows application is designed around local billing and encrypted device storage. Online services, payment verification and future synchronization have separate availability requirements.

Can I download it on my phone today?

Android, iPhone and iPad foundations are in development. There is no public mobile release linked here. The current companion uses clearly labelled demo data; live billing and synchronization are not yet enabled.

Are all industry workflows available?

The shared core and grocery stock-review workflow are implemented in development source. Restaurant tables and kitchen tickets, salon appointments, gym memberships and attendance, serial numbers and warranties remain planned native features.

When will Windows downloads open?

When a genuine installer has completed the required native financial, security, installation and lifecycle verification. This page only enables a download when a verified official release is configured.
